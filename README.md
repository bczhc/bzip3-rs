# bzip3-rs

This is a Rust wrapper for [bzip3](https://github.com/iczelia/bzip3).

[![](https://img.shields.io/crates/v/bzip3)](https://crates.io/crates/bzip3)

[Documentation](https://docs.rs/bzip3/latest/bzip3)

## Crate Features

- bundled: use bundled libbzip3

  Current bundled bzip3 library version
  is [iczelia/bzip3@1.5.3](https://github.com/iczelia/bzip3/commit/53984efe378df61a4d3eb41637355c453eec338f).
